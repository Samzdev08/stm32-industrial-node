# stm32-industrial-node

Nœud industriel basé sur STM32.

## Structure

| Dossier              | Contenu                                |
|----------------------|----------------------------------------|
| `firmware/`          | Code embarqué STM32                    |
| `hardware/`          | Schémas, PCB                           |
| `dashboard/`         | Interface de visualisation des données |
| `measurements/`      | Mesures et résultats de tests          |
| `tests/`             | Tests                                  |
| `docs/adr/`          | Architecture Decision Records          |
| `.github/workflows/` | CI GitHub Actions                      |
